# Звёздная ночь — бронирование куполов под звёздами

Учебный сайт бронирования глэмпинга на горном склоне. Пользователь выбирает даты и
прозрачный купол на схеме склона или в списке, видит сумму и прогноз неба,
подтверждает бронь, а потом может изменить её, распечатать талон или отменить.

**Сайт:** [ссылка на GitHub Pages]
**Репозиторий:** [ссылка на GitHub]

> **Учебное демо: бронирования сохраняются только в этом браузере.**
> Реальная бронь и оплата не оформляются. Купола, цены и место вымышленные.

## Тема

Своя тема, похожая на «Загородные дома» из задания: 8 куполов-глэмпингов на склоне
с озером, лесом, костровой и обсерваторией. Часть ночей уже занята другими гостями.

## Функции

### Минимальная версия
- **Схема склона** (собственная SVG-схема) и **список** — строятся по одному массиву `js/data.js`.
- **Состояния не только цветом:** на схеме — форма значка (огонёк / ✓ / ✕ / ★) и легенда;
  в списке — плашка «Выбран / Занят / Ваша бронь», занятые фото чёрно-белые.
- **Фильтры:** число гостей, максимальная цена, «с телескопом», «Сбросить».
  Схема и список показывают одинаковый результат; пустой результат — подсказка;
  если фильтр скрыл выбранный купол — выбор сбрасывается с сообщением.
- **Карточка купола:** описание, цена, форма (даты, гости, экскурсия), итоговая сумма.
- **Проверка:** гостей — от 1 до вместимости, ночей — от 1 до 30; ошибка у поля, бронь не создаётся.
- **Подтверждение** создаёт одну бронь (ЗН-0001…), двойное нажатие дубликат не создаёт.
- **Мои брони** с общим итогом; отмена с подтверждением освобождает купол.
- **Сохранение** в localStorage под ключом `zvezdnaya-noch:v2`; повреждённые данные и запрет
  сохранения не ломают страницу. «Сбросить демо» удаляет только свой ключ.
- **Телефон и клавиатура:** все купола и дни календаря — кнопки, фокус виден, у полей есть подписи.

### Дополнительно
- **Брони по датам (усложнение из задания).** Календарь заезда и выезда; купол занят только
  на конкретные ночи. Карта и список показывают свободные купола на выбранные даты.
  В календаре купола занятые ночи зачёркнуты, и захватить их нельзя: выезд ограничен
  первой занятой ночью. Пересечение дат проверяется ещё раз перед сохранением.
- **Фаза луны.** Считается по формуле синодического месяца, без API. В календаре отмечены
  тёмные ночи, новолуние 🌑 и полнолуние 🌕; для выбранных дат — прогноз неба
  («Тёмные ночи», «Хорошее небо», «Яркая луна»).
- **Цена по ночам:** ночи пятницы и субботы +20%, от 7 ночей скидка 10%, экскурсия +1 500 ₽.
  Расчёт показывает разбивку по строкам.
- **Галерея** из трёх фото в карточке купола.
- **Сортировка** списка: сначала свободные, дешевле, дороже, вместительнее.
- **Изменение брони:** даты, гости и экскурсия меняются без отмены; номер брони сохраняется.
- **Талон:** аккуратная карточка брони для печати или сохранения в PDF через окно печати.

## Запуск

Проект на ES-модулях, поэтому `index.html` нельзя открыть двойным кликом — нужен локальный сервер:

- **VS Code:** расширение Live Server → правой кнопкой по `index.html` → «Open with Live Server».
- **Терминал** в папке проекта: `python -m http.server 8000` → http://localhost:8000

Сборка, npm, сервер и платные карты не нужны.

## Публикация (GitHub Pages)

1. Загрузить файлы в репозиторий (`index.html` в корне).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Структура

```
index.html
css/style.css
js/
  main.js       — состояние, занятость по датам, выбор, бронь/изменение/отмена, фильтры, сортировка
  data.js       — купола (цена, вместимость, координаты, занятые ночи, фото), правила цен
  dates.js      — даты: форматирование, ночи, пересечение периодов
  moon.js       — фаза луны и прогноз неба
  pricing.js    — проверка формы и расчёт суммы по ночам
  calendar.js   — календарь выбора дат
  map.js        — схема склона и кнопки-купола
  list.js       — фото-карточки куполов
  card.js       — карточка купола: галерея, форма, итог, успешная бронь
  bookings.js   — «Мои брони» и общий итог
  print.js      — талон для печати
  storage.js    — чтение/запись localStorage с проверкой данных
  utils.js      — деньги, склонения, фото с запасным фоном
```

## Нейросеть

Сайт собран по шагам с помощью **Claude** (Anthropic).

Полезные промпты:

1. > Создай сайт бронирования куполов-глэмпинга «Звёздная ночь» на HTML/CSS/ванильном JS, без React, npm, сервера и платных карт. На странице: фильтры, собственная схема склона с озером, лесом, дорогой и обсерваторией, кнопки-купола поверх схемы, список куполов, карточка выбранного купола и «Мои брони». 8 куполов с разными ценами и вместимостью. Используй ES-модули.

2. > Замени «число ночей» на календарь дат заезда и выезда. Купол занят только на конкретные ночи; карта и список показывают свободные купола на выбранные даты. В календаре купола зачеркни занятые ночи и не давай выбрать период, который с ними пересекается. Отметь тёмные ночи по фазе луны (без API, по формуле) и покажи прогноз неба на выбранные даты.

3. > Проверь и исправь: выбор через схему и список, фильтры, неверные значения, двойной клик подтверждения, обновление страницы, изменение и отмену брони, повторную бронь. Сохрани оформление и работающие функции.

## Проверка

- [x] Выбрать даты и свободный купол, изменить гостей — сумма меняется сразу
- [x] Выходные дороже, от 7 ночей скидка — видно в разбивке
- [x] Подтвердить, обновить страницу — бронь на месте, купол «ваша бронь» на эти даты
- [x] Изменить бронь — новые даты и сумма, номер тот же, дубликата нет
- [x] Отменить — купол снова свободен; забронировать его ещё раз
- [x] Занятый купол не выбирается; занятые ночи в календаре не выбираются
- [x] Неверные значения — ошибка у поля, брони нет; фильтр без результатов — подсказка
- [x] Двойное нажатие «Забронировать» — одна бронь
- [x] Телефон: одна колонка, без горизонтальной прокрутки; выбор и календарь с клавиатуры
